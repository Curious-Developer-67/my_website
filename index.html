About

How it works

The Ripple Effect is a consequence simulator set in Deoghar, Jharkhand. Nothing here is scripted — every scenario, consequence, and report is written live by Google's Gemini model, then measured against five dials of the town's future: Environment, Economy, Health, Community, and Innovation.

  1. 1Paste a free Gemini API key. It stays on your device and is sent only to Google — never to this page's author.
  2. 2Choose a vantage point: Mayor, Founder, Citizen, or Student. Each starts the town in a different shape.
  3. 3Play five turns. Read each scenario and commit to a path — or ignore the options and write your own directive.
  4. 4Watch the ripples: the gauges shift, the Deoghar Wire fills with headlines, and the pond behind everything darkens or brightens with the world's pulse.
  5. 5Receive a legacy report — charts, strengths, unresolved risks, and the world you left behind. Copy it, or run again with a different role.

Keyboard: 1 2 3 pick a choice · Enter continue · Esc close dialogs.

Built by Abhigyan Aditya, Saint Francis School, Jasidih — with HTML, CSS, JavaScript, the Gemini API, and Chart.js.
